# Coffee Ordering App

A multi-screen coffee-ordering application created using JavaScript and Code.org App Lab. Users can create an account, log in, browse the coffee menu and place an order.

## Features

* Account creation and login
* Interactive coffee menu
* Multi-screen navigation
* Order selection and processing
* User data storage using App Lab tables

## Technologies

* JavaScript
* Code.org App Lab
* Event-driven programming
* App Lab data tables

## Security Note

This is an educational prototype rather than a production-ready authentication system. A future version would use server-side validation, password hashing, secure sessions and improved access controls.
